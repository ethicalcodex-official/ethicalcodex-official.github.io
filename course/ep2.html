The OSI Model: 7 Layers Deep Dive

How data travels from your application across physical cables and routers to reach another server. Understand the 7 layers, packet encapsulation, and how security attacks target specific layers.

1. The 7 Layers of the OSI Model

The Open Systems Interconnection (OSI) model standardizes the communication functions of a telecommunication or computing system. A helpful mnemonic to remember the order from bottom (Layer 1) to top (Layer 7) is: "Please Do Not Throw Sausage Pizza Away".

Layer 7 — Application Layer (HTTP, HTTPS, SSH, DNS)

Directly interfaces with end-user software like web browsers and email clients.

Layer 6 — Presentation Layer (TLS/SSL, Compression, Encoding)

Handles encryption, decryption, and data translation into formats software can consume.

Layer 5 — Session Layer (RPC, NetBIOS)

Establishes, maintains, and terminates communication sessions between local and remote apps.

Layer 4 — Transport Layer (TCP, UDP)

Manages port numbers, flow control, packet reassembly, and error correction.

Layer 3 — Network Layer (IP, ICMP, Routers)

Routes packets across multiple interconnected networks using IP addresses.

Layer 2 — Data Link Layer (Ethernet, MAC Addresses, Switches)

Frames data and transfers packets between devices on the same local physical network.

Layer 1 — Physical Layer (Cables, Radio Waves, Fiber)

Transmits raw, unstructured electrical pulses, light, or radio frequencies representing binary bits (0s and 1s).

2. Inspecting Packets on Linux

Run these commands in your terminal to see live network packets passing through your system:

BASH — Capture the first 5 network packets passing through any interface 
sudo tcpdump -i any -c 5 -nn
BASH — Display the local ARP table (Layer 2 MAC to Layer 3 IP mapping) 
ip neigh show
