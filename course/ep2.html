OSI Model: 7 Layers की गहरी समझ

डेटा आपके कीबोर्ड से निकलकर दुनिया के दूसरे कोने तक कैसे पहुँचता है? सातों लेयर्स और पैकेट एनकैप्सुलेशन की विस्तृत यात्रा।

💡 हैकर टिप: जब कोई हैकर नेटवर्क पर हमला करता है, तो वह किसी खास लेयर (जैसे L2 ARP Spoofing, L3 IP Spoofing, L4 SYN Flood, या L7 SQL Injection) को टारगेट करता है।

1. सातों लेयर्स का आसान वर्गीकरण

याद रखने की ट्रिक: "Please Do Not Throw Sausage Pizza Away" (Physical, Data Link, Network, Transport, Session, Presentation, Application)

Layer 7: Application Layer (HTTP, HTTPS, SSH, FTP, DNS)

उपयोगकर्ता जिस ऐप से सीधे संपर्क करता है (जैसे आपका वेब ब्राउज़र)।

Layer 6: Presentation Layer (SSL/TLS, JPEG, ASCII)

डेटा का स्वरूपण, एन्क्रिप्शन और कम्प्रेशन।

Layer 5: Session Layer (RPC, NetBIOS)

दो कंप्यूटरों के बीच कनेक्शन स्थापित करना और उसे बनाए रखना।

Layer 4: Transport Layer (TCP, UDP)

पोर्ट नंबर, एरर करेक्शन, फ्लो कंट्रोल और सेगमेंटेशन।

Layer 3: Network Layer (IP, ICMP, Routers)

IP एड्रेसिंग और पैकेट को बेस्ट रूट से डेस्टिनेशन तक पहुँचाना।

Layer 2: Data Link Layer (MAC Address, Switches)

फ्रेमिंग और एक ही लोकल नेटवर्क में स्विच के जरिए डेटा भेजना।

Layer 1: Physical Layer (Cables, Radio Waves, Bits)

केबल्स, फाइबर या रेडियो तरंगों के जरिए 0 और 1 (विद्युत तरंगों) का संचरण।

2. व्यावहारिक पैकेट इंस्पेक्शन कमांड्स

BASH - लाइव पैकेट्स कैप्चर करना (L3/L4 स्तर पर) 
sudo tcpdump -i any -c 5 -nn
BASH - ARP टेबल देखना (Layer 2 MAC से L3 IP मैपिंग) 
ip neigh show
