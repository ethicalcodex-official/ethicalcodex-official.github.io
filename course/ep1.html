IP Addresses, Classes & Subnetting Fundamentals

हर इंटरनेट डिवाइस की पहचान: समझें IPv4, IPv6, Public vs Private IP और अपने लिनक्स टर्मिनल पर IP कॉन्फ़िगरेशन चेक करना।

1. IP Address क्या है और यह क्यों जरूरी है?

जैसे वास्तविक दुनिया में डाक पहुँचाने के लिए हर घर का एक भौतिक पता (Address) होता है, ठीक उसी तरह डिजिटल दुनिया में नेटवर्क से जुड़े हर उपकरण (Computer, Server, Mobile, Router) को एक अद्वितीय तार्किक पहचान (Logical Identifier) दी जाती है, जिसे IP (Internet Protocol) Address कहते हैं।

एक एथिकल हैकर के रूप में, आपका पहला काम किसी भी लक्ष्य (Target) के IP एड्रेस की पहचान करना और यह समझना होता है कि वह नेटवर्क में आंतरिक (Internal) है या बाहरी (Public facing)।

IPv4 vs IPv6: मुख्य अंतर

  • IPv4 (32-Bit): 4 ऑक्टेट्स में विभाजित (उदा. 192.168.1.1)। इसमें कुल लगभग 4.3 बिलियन पते संभव हैं, जो दुनिया की बढ़ती आबादी और डिवाइसेज के कारण कम पड़ रहे हैं।
  • IPv6 (128-Bit): हेक्साडेसिमल प्रारूप में (उदा. 2001:0db8:85a3::8a2e:0370:7334)। इसमें अनगिनत (लगभग 340 अनडिसीलियन) पते उपलब्ध हैं।

Public IP बनाम Private IP

इंटरनेट पर केवल Public IP ही राउट हो सकता है। आपके घर के वाई-फाई राउटर को आपके ISP से एक पब्लिक IP मिलता है, जबकि आपके घर के अंदर के लैपटॉप और फोन को Private IP (जैसे 192.168.x.x या 10.x.x.x) मिलता है, जिसे NAT (Network Address Translation) के जरिए बाहर भेजा जाता है।

2. व्यावहारिक Kali Linux कमांड्स

अपने सिस्टम का IP एड्रेस, नेटवर्क इंटरफेस और कनेक्टिविटी की जांच करने के लिए ये कमांड्स चलाएं:

BASH - नेटवर्क इंटरफेस और IP देखना 
ip -c a

* -c फ्लैग कलरफुल आउटपुट देता है ताकि inet (IPv4) आसानी से दिखे।

BASH - डिफॉल्ट गेटवे (राउटर का IP) जानना 
ip route show default
BASH - अपना पब्लिक IP एड्रेस टर्मिनल से चेक करना 
curl -s https://api.ipify.org
BASH - कनेक्टिविटी जांचने के लिए 3 पिंग भेजना 
ping -c 3 8.8.8.8
