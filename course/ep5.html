Ports & Protocols: Digital Gateways

Every networked operating system has up to 65,535 logical ports. Learn the standard port allocations, how to check open ports with Netcat, and how banner grabbing reveals service software versions.

1. Port Categories & Standard Allocations

Port numbers are 16-bit integers ranging from 0 to 65,535, divided into three standard tiers:

  • 0 – 1023: Well-Known Ports: Reserved for core operating system services and ubiquitous internet protocols (such as SSH, HTTP, and DNS).
  • 1024 – 49151: Registered Ports: Assigned by IANA for specific vendor applications and databases (such as MySQL on 3306 or PostgreSQL on 5432).
  • 49152 – 65535: Dynamic / Ephemeral Ports: Temporary ports assigned dynamically by your operating system client for outgoing communication.
Port Protocol Service Security Significance
21 TCP FTP Transmits authentication credentials in plaintext
22 TCP SSH Encrypted remote terminal shell session
23 TCP Telnet Legacy unencrypted terminal communication
53 UDP/TCP DNS Standard queries use UDP; large zone transfers use TCP
80 TCP HTTP Unencrypted plaintext web traffic
443 TCP HTTPS TLS/SSL encrypted secure web traffic
3306 TCP MySQL Database service port; should never be exposed publicly

2. Netcat (nc) Port Probing & Banner Grabbing

Netcat is known as the "Swiss Army knife" of networking. Use it to check if a specific port is accepting connections:

BASH — Check if port 22 is open on localhost 
nc -zv 127.0.0.1 22

* Flags: -z sets zero-I/O mode (scans without sending payload data), and -v enables verbose output.

BASH — Probe a specific port range (20 through 80) 
nc -zv 127.0.0.1 20-80
BASH — Perform HTTP banner grabbing using curl 
curl -I https://google.com
